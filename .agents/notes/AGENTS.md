# Agent Note instructions

This tree preserves consequential decisions and their evidence. Follow the canonical [lifecycle reference](../../skills/make-codebase-agentic-agent-notes/references/lifecycle.md), and keep [the index](README.md) useful for discovery.

Before adding a note, inspect the current decision owner and any supersession. A partial refinement keeps both useful records active and cross-linked. Keep implemented facts current while preserving the rationale; put a reversal in a new decision. Archived records, if introduced, are frozen history.

Link plans and phases for delivery status. An implemented decision does not establish that every acceptance criterion or device check passed. Run `python3 scripts/check.py` from the repository root to check lifecycle placement and file links; assess the substance separately.
