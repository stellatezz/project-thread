# Readable repository guidance and Make Codebase Agentic identity

Status: proposed

## Problem

The suite captures repository record ownership but leaves much of documentation structure and editorial judgment implicit. The user wants the technical depth, navigation, and language quality seen in DeepSeek Harness, and approved the Make Codebase Agentic rename.

## Proposal

Keep eleven skills. Documentation owns focused references for structure, precise prose, codebase explanations, instruction hierarchy, and worked examples. Engineering owns code organization. Setup and review load those owners when needed. The bundle demonstrates useful subtree instructions and preserves one source for each standard.

Rename the source directory, public repository, plugin, skill identifiers, UI invocations, and packaging to `make-codebase-agentic`. Use version 0.2.0 for the changed identity and substantive guidance. Provide explicit migration from owned Project Thread skill links, including broken links after a move. Preserve raw historical evaluations and original license attribution.

## Alternatives considered

Renaming only the README would leave discovery, installation, and references inconsistent. Keeping permanent alias skills would duplicate discovery and exceed the eleven-skill boundary. Adding several prose-specific public skills would overlap documentation and make routing less clear. Copying DeepSeek's full instructions would import product-specific tooling, runtime rules, and bilingual obligations. A word-count target would reward losing conditions and guarantees rather than improving understanding.

## Consequences and unresolved work

The skill prefix changes, so current invocations and installation links need migration. Existing adopting-project record filenames remain valid; the installer does not rewrite them. The original engineering and roadmap decisions remain active and are partially refined by this proposal. Independent task results and final installation/publication verification are pending.

## Acceptance and verification

The [plan](../../../../docs/roadmaps/skill-suite/plans/readable-agentic-codebase.md) owns acceptance criteria and the [phase](../../../../docs/roadmaps/skill-suite/phases/readable-agentic-codebase/01-revamp-and-migrate.md) records actual evidence. Test source migration, structural validity, portable distribution, prose outcomes, and instruction adoption separately; do not infer host discovery or iOS device behavior from these checks.
