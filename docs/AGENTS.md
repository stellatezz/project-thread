# Documentation instructions

This tree owns the bundle's current architecture, installation/testing explanations, and delivery records. Start at [the context map](codebase.md). The [record map](../skills/make-codebase-agentic/references/records.md) defines ownership; plans and checkpoints carry execution status.

Apply [document structure](../skills/make-codebase-agentic-documentation/references/document-structure.md) when placing detail and [technical writing](../skills/make-codebase-agentic-documentation/references/technical-writing.md) when editing prose. Keep complete conditions, failures, and guarantees. References describe current behavior; old evaluation artifacts retain their original evidence and terminology.

Repair incoming links when moving a document. Run `python3 scripts/check.py` from the repository root after changing links or records. Readability and factual accuracy also need semantic review; the checker validates file links, not heading anchors or meaning.
