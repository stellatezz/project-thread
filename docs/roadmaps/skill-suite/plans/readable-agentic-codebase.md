## Acceptance criteria

- Documentation teaches structure, technical prose, code explanations, instruction hierarchy, and worked examples through focused references.
- Engineering teaches maintainable code organization, with setup and review reusing the correct owners.
- Root and useful subtree instructions demonstrate the approach without duplicating the standards.
- Local directory, GitHub repository, skill names, UI invocations, plugin metadata, package identity, current docs, and user installation agree on `make-codebase-agentic`.
- A repeatable installer migration preserves unrelated entries, handles broken old links, and does not remove legacy links before new installation succeeds.
- Realistic isolated tasks exercise prose quality and repository adoption; conclusions distinguish file validity, instruction discovery, behavior, and unavailable hosts.
- Required bundle/helper and authoring checks pass; the complete archive installs after extraction. The public remote receives the verified change.
