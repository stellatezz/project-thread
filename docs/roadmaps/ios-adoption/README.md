# iOS-adoption roadmap

Scope: evaluating Make Codebase Agentic in a real native iOS client and using observed needs to improve the suite. [Project index](../../roadmap.md).

| Outcome | Status | Dependencies | Requirement/plan owner |
| --- | --- | --- | --- |
| Exercise the suite on one real iOS product slice | Candidate | The [skill suite's validated bundle](../skill-suite/README.md), selection of an app repository, and an agreed product requirement | No adopting app or feature plan selected yet |

Before promoting the candidate to ready work, select the actual app and requirement, identify the owning feature plan, and define its supported environments and evidence. Start with one complete journey and retain the app's architecture. The bundle's extracted fixture results do not satisfy that app's simulator, accessibility, or device criteria.

This implementation request does not authorize work in a separate app. Confirmed adoption findings may become requirements for plans owned by the skill-suite roadmap; no speculative app scope, schedule, or measurements are assigned here.
