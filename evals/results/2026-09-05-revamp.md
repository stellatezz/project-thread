# Make Codebase Agentic revamp evaluation

Date: 2026-09-05. Source identity: Make Codebase Agentic 0.2.0. These results cover the documentation/instruction revamp and renamed bundle. The [v1 results](2026-09-05-v1.md) retain their original artifacts and claims.

## Evaluation method

Two independent Codex agents each received a realistic task, raw artifacts in a separate temporary workspace, and the relevant skill entry point. They did not receive the scoring criteria, intended answer, parent conversation, or each other's output. The author reviewed the resulting files against the original inputs and source behavior. Skill-creator's independent forward-testing guidance supplied this method.

## Semantic review

The prose result describes the actual Python storage behavior: the parent directory must exist, JSON serialization has limits, the destination is replaced after temporary-file synchronization, and exceptions remain visible. It retains the difference between failure cleanup and a crash-recovery guarantee. It marks the supplied UI serialization description as integration context, because the raw sample contains no caller. Its API reference is detailed enough to explain cleanup failures and format conversion without copying the original control-flow narration.

The adoption result keeps the original root rules and all six other raw files intact. Its explicit reading path connects root and writer rules, product behavior, source, and the existing CLI test. The author independently compared the preserved bytes with the inputs. The result distinguishes source inspection, manual reading, executed CLI behavior, and unverified host loading. No supported failure required a further skill change after these exercises.

These are bounded examples of useful behavior, not a general benchmark of prose quality or autonomous development. Code-organization guidance received source/editorial review; this revamp does not claim a new application-level coding evaluation.

## Executed verification

- The documentation evaluator ran the README example and 13 storage scenarios. The exact [verification script](revamp/prose/verification.py) and [original output](revamp/prose/verification-original.log) are retained. The author replayed that script against the retained output: all 13 scenarios and the example passed, and the source checksum remained unchanged. [Replay output](revamp/prose/verification-parent-replay.log).
- The adoption evaluator ran the existing CLI test before and after adoption, exercised successful UTF-8 output, rejected overwrite, and missing-parent failure, and checked preserved hashes and 41 local links. Its report retains the commands and results. The first baseline test used and cleaned Python's default temporary directory outside the isolated repository; later checks confined fixtures to the workspace. No persistent external artifact was reported.
- The bundle's structural/file-link checker, all eleven Codex skill validators, plugin validation, and 16 helper tests passed. The helper tests include renamed archive extraction/install and repeatability, plus migration preflight, broken legacy links, preserved other sources, rollback, and cleanup retry.
- All eleven user installation links resolve to the renamed source checkout. Repeated migration preview preserves them and no legacy Project Thread entries remain. The public GitHub name and description match the new identity. The delivery [phase](../../docs/roadmaps/skill-suite/phases/readable-agentic-codebase/01-revamp-and-migrate.md) owns final publication status.

The Python fixture runs used Python 3.14.4. Failure injection does not demonstrate real disk exhaustion, power-loss durability, or platform equivalence. Neither exercise proves automatic instruction discovery in a fresh Codex or Claude host. Claude was unavailable, and the adoption output preserves that limitation. No new Swift, simulator, physical-device, backend, or release verification occurred.
