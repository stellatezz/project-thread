# Skill authoring instructions

This tree supplies twelve public skills. Each entry point states its scope and routes to relevant supporting references. Discovery names, folder names, and UI invocations must agree. Shared record and lifecycle rules retain their existing owners.

Use [technical writing](make-codebase-agentic-documentation/references/technical-writing.md) to preserve operational meaning and [worked examples](make-codebase-agentic-documentation/references/worked-examples.md) to resolve editorial tradeoffs. Give references enough detail to change a reader's decisions without requiring every task to load every file.

Validate changed skills and plugin metadata using [the testing guide](../docs/testing.md). Substantial guidance changes need a realistic task exercise; matching phrases in the instructions is not behavioral validation. Keep fixtures isolated and report the evidence actually produced.
